subs2dub

Generate a synced dub from a video's existing subtitle track. The subtitles are the script; their timings are the sync target.

Approach

Script

Subtitles, not transcription

Whisper-based pipelines discard a human translation and add transcription error. The subtitle file is used directly.

Cast

Voices from the original

Speech is separated from music, each line attributed to a speaker, and every character cloned from a reference clip of the actor.

Timing

The actor's tempo

Lines are fitted to how long the original speaks, measured from the vocal stem — not to how long a subtitle sits on screen.

Mix

The room stays

The original cast is kept quietly underneath and ducked, so laughter and reactions survive rather than being stripped out.

Autoregressive engines generate audio one token at a time and can stall mid-line or fail to stop. StyleTTS2 predicts phoneme durations in a single pass, which makes both failure modes impossible and accounts for the order-of-magnitude difference.

Verification

Fit statistics do not say whether a result is listenable — a line can fit because half of it was cut. Every render inspects its own audio and names what is wrong.

Clips that fail are redrawn before reaching the track. Per-cue detail is written to render.json.

Automatic captions

Auto-captions are not subtitles. They arrive as a rolling window — each event repeats the previous words and appends a few — and carry no sentence punctuation.

Read literally, the dialogue multiplies and the dub has to race to fit words nobody said twice. The track is classified and only the repairs it needs are applied.

Install

# macOS
brew install ffmpeg rubberband espeak-ng

git clone https://github.com/prvrtl/subs2dub.git
cd subs2dub
./scripts/setup.sh
./scripts/setup.sh --styletts2      # Ukrainian speech

# interactive, with a runtime estimate
./bin/subs2dub

# English source, Ukrainian dub
./bin/subs2dub movie.mkv -o out.mkv \
    --backend styletts2 --target-lang uk --translate-llm

Python 3.10 or 3.11. Model weights (~8 GB) download on first run. 16 GB RAM is sufficient; stages run sequentially and release their models.

Limitations

  • Lip sync is approximate; phoneme-accurate sync requires a video model.
  • Emotion is derived from delivery loudness, capturing arousal but not valence — it cannot separate frightened from furious.
  • Phone calls, shouting and whispering can split one character in two.
  • Songs are removed by separation and are not dubbed.
  • Synthesized Ukrainian runs at 10–13 characters per second. A source speaking at 18 leaves the translator no option but to condense. Scripted film sits inside this range; unscripted speech often does not.
  • Verification detects structural faults, not whether a delivery sounds right. Listen before shipping.
